Kegunaan Fungsi Program

1.muat_data(): untuk membuka dan membaca file nilai_mahasiswa.json agar datanya bisa dipakai di program.

2. simpan_data(data): untuk ngesave data terbaru ke file nilai_mahasiswa.json biar tidak hilang ketika program ditutup.

4. tampilkan_nilai(data): untuk menampilkan semua data NIM, Nama, dan Nilai yang sudah tersimpan ke layar.

5. tambah_nilai(data): untuk nampung data baru yang kita ketik, lalu dimasukan ke dalam daftar nilai.

6. main(): kontrol program yang ada di menu utama (bisa pilih menu 1, 2, atau 3).

7. json.load(): untuk membaca file nilai_mahasiswa.json.
   
8. json.dump(): untuk menulis/menyimpan data permanen.

9. input(): untuk menerima apa pun yang diketik di terminal.
  
11. data.append(): untuk menempelkan data mahasiswa yang baru ditambahkan ke barisan paling bawah.
    
12. float(): Merubah teks input nilai menjadi angka desimal.
